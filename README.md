# கிர்திக் & நிக்கிலா — Wedding Invitation

The Tamil watercolor wedding invitation, prepared for free GitHub Pages hosting.

## Publish on GitHub Pages

1. Sign in to GitHub as `KirthikRoshan`.
2. Create a new **public** repository named **`wedding`**. Do not replace the existing `KirthikRoshan.github.io` portfolio repository.
3. Upload the contents of this package to the **root** of the `main` branch: `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the complete `assets/` folder. Commit the files.
4. In the `wedding` repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**; select **main** and **/(root)**, then **Save**.
6. After GitHub finishes publishing (often a few minutes), visit <https://kirthikroshan.github.io/wedding/>.

## What this includes

- Tamil ceremony, reception, venue and directions
- Animated watercolor couple portrait and floral effects
- Wedding countdown, WhatsApp sharing, downloadable calendar events
- Mobile-friendly design; no build process or paid hosting necessary

The site's WhatsApp share button automatically uses the current hosted URL. The Open Graph metadata is configured for the `/wedding/` GitHub Pages address. If you choose a different repository name, update the two `og:` URLs in `index.html` accordingly.

## Update later

Edit or upload the changed files to the same `main` branch. GitHub Pages publishes new commits automatically.
